# Hamza Sultan — Personal Portfolio

Responsive personal portfolio for **Hamza Sultan**, Software Developer + UI/UX, built with HTML5, CSS3, vanilla JavaScript, and Bootstrap 5.

## Features
- Responsive layout for mobile, tablet, and desktop
- Custom dark premium visual identity
- Project filters: All work, Products, Websites
- Accessible navigation labels and keyboard focus styles
- Reduced-motion preference respected
- Project links to GitHub repositories and available live demos
- CSS-built project artwork; no local image assets required

## Run locally
Open `index.html` in a browser. Bootstrap 5 and Google Fonts load from CDNs, so internet access is required for those assets.

## Before using for job applications
- Add a professional email and LinkedIn profile if you want them public.
- Confirm project descriptions accurately reflect your contribution and current status.
- Add screenshots and a resume/CV when ready.

HTML5 · CSS3 · JavaScript · Bootstrap 5
